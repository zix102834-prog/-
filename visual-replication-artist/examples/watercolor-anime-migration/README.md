## 参考职责：不可混用

| 参考输入 | 它负责什么 | 不负责什么 |
| --- | --- | --- |
| 原图 | 整体画风、氛围、材质语言、线条、水彩渗染和纸张质感 | 改写新主体、动作或素材图的取景 |
| 拆解图 | 视觉层级、构图关系的抽象说明、焦点与画面组织 | 成为主风格图，或把拆解图中的人物/动作搬进成图 |
| 素材图 | 主体身份、人数、服装、道具、环境、动作、视线、画面与构图 | 被其他参考图替换成不同故事或姿态 |
| 额外色彩图 | 仅提供色相、明度、饱和度、配色比例与冷暖关系 | 提供人物、动作、镜头、构图或叙事 |

## 成图锁定规则

最终成图的画面、人物动作、肢体方向、主体关系、镜头景别与构图必须和素材图一致。发生冲突时，素材图对这些内容字段拥有最高优先级；原图只迁移画风，拆解图只提供抽象结构说明，额外色彩图只影响配色，绝不借用其动作。

生成提示中应明确写入：

> 保持素材图的主体身份、人物数量、动作、视线、道具、场景、取景和构图不变；仅迁移原图的水彩动漫画风与纸张肌理。拆解图只作视觉组织说明。额外色彩图只作调色板参考，不参考其中的人物、动作、镜头或构图。

## 水彩动漫迁移检查

- 保留素材图的故事瞬间，不把色彩参考图或原图中的姿势带入成图。
- 以通透水彩叠染、可见纸纹、自然留白、松弛线稿和局部色彩跳跃统一画面。
- 用配色参考调整色相与冷暖后，复查人物动作、镜头和构图是否仍与素材图一一对应。
- 只迁移可观察的视觉语言；不复制任何来源的角色身份、标识、原有文字或专属道具。
