# Changelog

## 1.2.0 — 2026-09-19

- 新增 Windows 原生的确定性 PNG 拆解图生成脚本。
- 新增源图与嵌入区域的像素级 SHA-256 校验及完整性报告。
- 所有标注均位于 1:1 原图区域之外，脚本禁止覆盖源文件。
- 精简 `SKILL.md`、交接 schema 与提示词专家契约之间的重复规则。
- 将行为评测版本与 schema 1.1 对齐。

## 1.1.0 — 2026-09-17

- 新增 `analysis-only`、`migration-planning` 和 `generate-now` 三种运行模式。
- 拆解图改为确定性合成要求，禁止生成式重绘原图。
- 子智能体新增 `explore`、`refine` 和 `finalize` 三种规划模式。
- 将餐饮标题层级规则限制为条件规则。
- 将 Poster Show 改为可选集成。
- 新增案例素材许可说明和行为评测用例。

## 1.0.0 — 2026-09-09

- 初始视觉拆解、迁移规划、生成包和提示词子智能体流程。
