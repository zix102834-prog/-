# 视觉复刻师 Skill

将一张参考海报拆成可复用的视觉关系，再为新的主体、场景和动作准备迁移提示词。

它复刻的是构图、层级、色彩角色、材质和阅读顺序，不复制原作的品牌、文案、人物、地点或标志性道具。

> **原图管风格，拆解图管结构，商品管主体，卖点管文案。**
>
> **结构可以继承，内容必须重新设计。**

## 能做什么

- 检视参考海报并提取可验证的视觉锚点。
- 生成标注式视觉拆解图，说明构图区域、视觉层级、色彩和文字角色。
- 通过「替换方案与提示词专家」提出可替换主体、环境和动作。
- 为选定方向提供完整迁移提示词、负面提示词与生图输入说明。

它不直接复制原海报，也不负责制作海报教学 HTML。

## 安装

将本仓库内的 `visual-replication-artist` 文件夹复制到自己的 Codex Skills 目录：

```text
~/.codex/skills/visual-replication-artist/
```

重启 Codex 或重新加载 Skills 后，可直接说：

```text
使用视觉复刻师，拆解这张海报；给我主体、场景和动作的迁移方案，并准备生图提示词。
```

## 快速开始

1. 上传一张完整、清晰的原海报。
2. 指定你要替换的主体，或让 Skill 先提出方向。
3. 查看视觉拆解图和迁移方案。
4. 确认一套「主体 + 场景 + 动作」与文案。
5. 将原图、视觉拆解图、确认提示词，以及可选的主体素材图放进下一步生图。

详见 [使用手册](使用手册.md)，迁移逻辑见 [案例解析](案例解析.md)。

## 参考素材与使用边界

仓库中的案例图仅用于说明 Skill 的迁移方法。使用者应只上传、公开或分发自己拥有权利或已获授权的参考图、素材图和品牌资产。生成或迁移时应避免复制原作文字、Logo、包装、人物身份与其他可识别内容。
